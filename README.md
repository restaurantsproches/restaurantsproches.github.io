# Restaurants Proches

French-language static site helping visitors find and enjoy restaurants in France:
"Trouvez un bon restaurant près de chez vous".

Live at: https://restaurantsproches.github.io/

## Tools (all in French, pure vanilla JS)

1. **Calculatrice de pourboire** — tip calculator (bill × percentage, split per person).
2. **Diviseur d'addition** — bill splitter with tip.
3. **Planificateur de budget restaurant** — monthly dining budget planner.
4. **Planificateur de réservation** — reservation planner with date, time, guests and occasion.
5. **Liste de contrôle régimes et allergies** — dietary/allergy checklist that builds a phrase to show the waiter.
